## What's new in 0.2.0

- **New name: Hypercube Office.** The app was called Hyper-Files before. Installing 0.2.0 replaces it, and your settings, recent files and starred files carry over.
- **OCR when you ask for it.** PDFs are no longer scanned for text automatically when you open them. To make a scanned PDF searchable and selectable, use **Recognize text** on the PDF viewer's Home tab, or **Recognize text (OCR)** in PDF Tools. It uses the OCR engine built into Windows and works offline. For now it adds Latin-script text only.
- **Updates from inside the app.** Settings > About now always has **Check now**. When a newer version is found, choose **Download and install**: the app downloads the installer from this repository, checks its SHA-256, then closes, installs the update and reopens. It asks you to save open documents first. The daily background check is still off until you turn it on.
- **Code signing policy.** The project now publishes how releases are built, reviewed and signed: [CODE_SIGNING_POLICY.md](https://github.com/omar-184/Hypercube-Office/blob/main/CODE_SIGNING_POLICY.md).

### Upgrading from 0.1.x

Install 0.2.0 by hand once: download the installer below and run it. Hyper-Files 0.1.0 and 0.1.1 cannot install updates themselves. From 0.2.0 on, updates install from Settings > About.

The installer is still not code-signed, so Windows SmartScreen may warn the first time you run it.
